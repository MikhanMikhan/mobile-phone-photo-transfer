# Фото с iPhone (IPhonePhotos)

Программа для Windows, которая копирует фото и видео с iPhone на компьютер
напрямую по кабелю (протокол AFC, без MTP и без iTunes-менеджера).

- Выбор периода: месяц, последняя неделя, последний месяц или произвольный диапазон дат.
- Раскладка по папкам `ГГГГ-ММ-ДД/фото|видео` (можно отключить).
- Пропуск уже скопированных файлов — можно запускать повторно.
- Параллельное скачивание, повторные попытки при сбоях, список ошибок в `unfixable.txt`.

## Быстрый старт (готовый .exe)

1. Установите **iTunes** (или только драйверы Apple Mobile Device Support) —
   без них Windows не видит iPhone как устройство для обмена данными.
2. Скачайте `IPhonePhotos.exe` из раздела **Releases**.
3. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять».
4. Запустите `IPhonePhotos.exe`, выберите папку и период, нажмите «Старт».

## Запуск из исходников

Нужен Python 3.10+ и установленные драйверы Apple (см. выше).

```bash
pip install -r requirements.txt
python iphone_photos_app.py
```

Также есть консольная версия без GUI:

```bash
python iphone_photos.py ПАПКА --month 2026-04
python iphone_photos.py ПАПКА --from 2026-05-01 --to 2026-06-15
```

## Сборка .exe

```bash
pyinstaller IPhonePhotos.spec
```

Готовый файл появится в `dist\IPhonePhotos.exe`.

## Как это работает

Используется библиотека [pymobiledevice3](https://github.com/doronz88/pymobiledevice3):
подключение через usbmuxd, чтение `/DCIM` через сервис AFC. Файлы выбираются
по дате модификации (mtime), служебные `.aae` пропускаются.
