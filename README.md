# Фото с телефона (mobile-phone-photo-transfer)

Программа для Windows, которая копирует фото и видео с телефона на компьютер
по кабелю. Поддерживаются **iPhone** (протокол AFC) и **Android** (ADB).

- Выбор периода: месяц, последняя неделя, последний месяц или произвольный диапазон дат.
- Раскладка по папкам `ГГГГ-ММ-ДД/фото|видео` (можно отключить).
- Пропуск уже скопированных файлов — можно запускать повторно.
- Параллельное скачивание, повторные попытки при сбоях, список ошибок в `unfixable.txt`.

## Быстрый старт (готовый .exe)

1. Скачайте `IPhonePhotos.exe` из раздела **Releases**.
2. Подготовьте телефон (см. ниже), подключите кабелем.
3. Запустите программу, выберите устройство, папку и период, нажмите «Старт».

### iPhone

- Установите драйверы Apple: либо `AppleMobileDeviceSupport64.msi` из раздела
  **Releases**, либо полный iTunes.
- Разблокируйте iPhone и нажмите «Доверять этому компьютеру».

### Android

- Включите **отладку по USB**: Настройки → О телефоне → 7 раз нажать
  «Номер сборки» (появится режим разработчика), затем Настройки →
  Для разработчиков → Отладка по USB.
- При первом подключении на экране телефона разрешите отладку для этого ПК.
- Программа сама скачает `adb` (Android platform-tools) с сайта Google
  при первом запуске — нужен интернет.
- Копируются `/sdcard/DCIM`, `/sdcard/Pictures`, `/sdcard/Movies`.

## Запуск из исходников

Нужен Python 3.10+, для iPhone — драйверы Apple (см. выше).

```bash
pip install -r requirements.txt
python iphone_photos_app.py
```

Также есть консольная версия только для iPhone:

```bash
python iphone_photos.py ПАПКА --month 2026-04
python iphone_photos.py ПАПКА --from 2026-05-01 --to 2026-06-15
```

## Сборка .exe

```bash
pyinstaller IPhonePhotos.spec
```

Готовый файл появится в `dist\IPhonePhotos.exe`.

## Как это работает

- **iPhone**: библиотека [pymobiledevice3](https://github.com/doronz88/pymobiledevice3) —
  подключение через usbmuxd, чтение `/DCIM` через сервис AFC.
- **Android**: `adb shell find/stat` для списка файлов, `adb pull` для скачивания.

Файлы выбираются по дате модификации (mtime), служебные `.aae` пропускаются.
